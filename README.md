# Учебная практика — Python программы

В архиве находятся две программы для кейс-задач по учебной практике.

## factorial.py
Программа запрашивает положительное целое число и вычисляет его факториал с помощью `math.factorial()`.

Запуск:
```bash
python factorial.py
```

## guess_number.py
Консольная игра «Угадай число». Программа загадывает число от 1 до 100, пользователь пытается угадать его за ограниченное количество попыток.

Запуск:
```bash
python guess_number.py
```
